# Henua Iti — sitio de propuesta

Sitio estático multipágina. La página de inicio es `index.html` y las imágenes están en `assets/`.

## Publicar en GitHub Pages

1. Descomprime el archivo ZIP en tu computador.
2. Sube **el contenido** de esta carpeta al nivel principal del repositorio: `index.html`, las páginas `.html`, los archivos `.css` y `.js`, y la carpeta `assets`. No subas solo el ZIP.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/(root)`, y guarda.
5. Espera a que termine la publicación. GitHub mostrará el enlace del sitio en esa misma sección.

No muevas `index.html` dentro de otra carpeta; debe quedar en la raíz del repositorio.
